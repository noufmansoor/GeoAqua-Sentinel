# GeoAqua Sentinel
AI-Powered IoT Platform for Smart Water Quality and Leakage Monitoring Using Earth Observation and Geospatial Analytics
## About the Project
GeoAqua Sentinel is a smart water monitoring system designed to support water sustainability in the UAE and wider Arab region.
The project combines Earth Observation, IoT sensors, Artificial Intelligence, and geospatial analytics to monitor water conditions, detect abnormal water quality, identify possible leakage, and provide early alerts.
## The Problem
Traditional water monitoring often depends on manual inspections and isolated sensors. This makes early detection of water contamination and leakage difficult.
GeoAqua Sentinel brings different data sources together to support faster detection and decision-making.
## Our Solution
GeoAqua Sentinel combines:
- Earth Observation satellite data
- IoT water sensors
- Artificial Intelligence
- Machine Learning
- Geospatial analytics
- GIS visualization
- Automated alerts
## Proof of Concept
Our current PoC includes:
- Planet Tanager hyperspectral imagery
- Water detection using NDWI
- Chlorophyll and algal bloom analysis using NDCI
- Turbidity analysis
- Synthetic IoT water sensor dataset
- 500 simulated IoT records
- Random Forest machine learning model
- Combined satellite and IoT alert logic
- Water flow monitoring
- Dashboard visualization
## IoT Parameters
The simulated IoT dataset contains:
- pH
- Turbidity
- Total Dissolved Solids (TDS)
- Temperature
- Water flow rate
## How GeoAqua Sentinel Works
1. Satellite imagery provides environmental information about the monitored area.
2. IoT sensors provide local water measurements.
3. AI analyzes the collected data.
4. Satellite and IoT results are combined.
5. Abnormal conditions trigger an alert.
6. Results are displayed through a monitoring dashboard.
## Current Project Status
The project is currently in the Proof of Concept stage for the Arab Youth Space Hackathon 2026.
The current PoC demonstrates satellite analysis, simulated IoT monitoring, AI-based classification, data fusion, and alert generation.
## Current Limitation
The IoT data used in the current PoC is synthetic. Future development will include physical IoT sensors and real field measurements for validation.
